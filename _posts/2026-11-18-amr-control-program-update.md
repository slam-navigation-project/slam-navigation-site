# AMR Control Program 기능 개선 및 경로 탐색 연동

## 1. 개발 개요

기존 AMR 제어 프로그램의 사용 편의성을 개선하고, SLAM을 통해 생성한 지도 데이터를 A* 경로 탐색 알고리즘과 연동할 수 있도록 기능을 수정하였다.

특히 원격 PC에서 라즈베리파이의 ROS2 노드를 실행하고, 지도 저장부터 목적지 지정 및 경로 시각화까지 하나의 프로그램에서 처리할 수 있도록 구성하였다.

## 2. 주요 수정 사항

![이미지]({{ site.baseurl }}/assets/img/posts/2026-11-18/2026-11-18-GUI.png)

### 2.1. 런처 실행 방식 변경

기존에 분리되어 있던 런처 실행 기능을 통합하여 **Mapping 모드 런처와 Foxglove Bridge를 동시에 실행**하도록 수정하였다.

- Mapping 런처와 Foxglove Bridge의 통합 실행
- SSH를 이용한 원격 ROS2 노드 실행
- 런처 및 브리지 종료 기능 통합
- 불필요한 Localization 실행 버튼 제거

이를 통해 별도의 터미널에서 각 노드를 실행할 필요 없이 GUI를 통해 지도 생성 환경을 구성할 수 있도록 개선하였다.

### 2.2. 지도 저장 기능 추가

SLAM을 통해 생성한 지도 데이터를 다양한 용도로 활용할 수 있도록 지도 저장 기능을 추가하였다.

**저장 파일 구성**

| 파일 형식 | 활용 목적 |
|---|---|
| `.pgm` | 생성된 2차원 지도 이미지 |
| `.yaml` | 지도 해상도 및 원점 정보 |
| `.npz` | NumPy 기반 2차원 배열 및 A* 경로 탐색 |
| `.posegraph` | SLAM의 포즈 그래프 정보 |
| `.data` | SLAM Toolbox 직렬화 데이터 |

`npz` 파일에는 점유 격자 정보를 2차원 배열 형태로 저장하여 별도의 이미지 변환 과정 없이 Python에서 활용할 수 있도록 하였다.

또한 로봇의 초기 전방을 기준으로 배열의 방향을 정렬하여 경로 탐색 시 일관된 좌표계를 사용하도록 구성하였다.

**지도 갱신 방식**

- 지도 저장 시 기존 파일과 동일한 이름으로 저장
- 새로운 파일 생성이 완료되면 기존 지도 파일 교체
- 저장 과정에서 오류가 발생하면 기존 데이터 보존

이를 통해 여러 차례 Mapping을 수행하더라도 최신 지도 데이터를 일관되게 관리할 수 있도록 하였다.

### 2.3. Grid Map 기반 도착지점 지정

기존에는 A* 경로 탐색의 시작점과 도착점을 코드에서 직접 지정하였으나, 이를 개선하여 **지도 시각화 화면에서 마우스 클릭으로 도착지점을 지정**할 수 있도록 구현하였다.

- 저장된 NPZ 파일에서 2차원 Grid Map 불러오기
- 원격 PC에서 지도 시각화
- 마우스 클릭을 통한 도착 셀 선택
- 장애물 및 미탐색 영역 선택 제한
- 선택된 도착지점까지 A* 알고리즘으로 경로 생성
- 탐색 결과를 지도 위에 시각화

현재 시작지점은 임시로 이동 가능한 셀을 지정하고 있으며, 추후 실제 AMR의 현재 위치를 반영하도록 개선할 예정이다.
![이미지]({{ site.baseurl }}/assets/img/posts/2026-11-18/2026-11-18-MAP.png)

### 2.4. 차량 조종 기능 추가

원격 PC에서 AMR을 직접 조종할 수 있도록 기존 `teleop_wasd.py`와 GUI를 연동하였다.

SSH 통신을 통해 라즈베리파이에서 조종 프로그램을 실행하며, GUI에서 입력한 명령을 전달하도록 구성하였다.

**주요 조종 기능**

| 입력 | 동작 |
|---|---|
| W | 전진 |
| S | 후진 |
| A | 좌회전 |
| D | 우회전 |
| Space | 정지 |
| Q | 조종 종료 |

이를 통해 별도로 VNC 환경을 실행하지 않고도 원격 PC에서 차량을 조종할 수 있도록 하였다.

## 3. 향후 구현 계획

### 3.1. 기존 관제 시스템 기능 통합

기존 관제 시스템에서 확인하던 차량 상태 정보를 현재 Control Program에 통합할 예정이다.

**추가 예정 정보**

- 차량의 실시간 위치 좌표
- 차량의 현재 방향각(Yaw)
- 좌우 바퀴의 각속도
- 차량의 주행 및 정지 상태

이를 통해 지도 생성, 경로 탐색, 차량 조종 및 상태 모니터링을 하나의 GUI에서 수행할 수 있도록 확장할 계획이다.

### 3.2. 차량의 현재 위치와 Grid Map 셀 좌표 연동

현재 A* 경로 탐색에서는 시작지점을 임의의 셀로 설정하고 있다.

이를 개선하기 위해 SLAM으로 추정한 차량의 현재 위치를 NPZ 지도상의 셀 좌표로 변환하는 기능을 구현할 예정이다.

**구현 과정**

1. SLAM 및 TF 데이터를 이용한 차량 위치 추정
2. 지도 원점과 해상도를 이용한 좌표 변환
3. 차량의 실제 위치가 포함된 Grid Map 셀 탐색
4. 해당 셀을 A* 경로 탐색의 시작점으로 설정
5. 사용자가 지정한 도착지점까지 경로 생성 및 시각화

특히 NPZ 지도는 초기 차량 방향에 맞춰 회전되어 있으므로, 좌표 변환 과정에서 지도의 회전각을 함께 반영해야 한다.

해당 기능을 구현하면 차량이 이동함에 따라 현재 위치를 갱신하고, 이를 기준으로 경로를 재탐색하는 기능으로 확장할 수 있을 것으로 예상된다.

## 4. 정리

이번 수정에서는 AMR Control Program의 기능을 통합하고, SLAM 지도 데이터를 경로 탐색에 활용할 수 있는 기반을 구축하였다.

현재는 **원격 지도 생성 → NPZ 배열 저장 → 도착지점 선택 → A* 경로 탐색 및 시각화**까지 연동한 상태이다.

향후 차량의 실시간 위치 및 주행 상태를 관제 프로그램에 통합하고, 실제 위치를 경로 탐색의 시작점으로 반영하여 자율주행 기능으로 확장할 계획이다.
